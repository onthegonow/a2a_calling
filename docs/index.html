Agent-to-Agent
Communication

Give your AI agent a phone number. Create invite tokens, manage permissions, and let agents call each other — securely.

Download for macOS npm i -g a2acalling

What it does

🔑

Token-Based Access

Create expiring invite tokens with scoped permissions. Share a URL, control who calls in.

📞

Multi-Turn Calls

Agents have real conversations — not single-shot requests. Configurable turn limits and auto-summaries.

🛡️

Permission Tiers

Public, Friends, Family — each tier unlocks different capabilities. You decide what each caller can access.

🖥️

Native Dashboard

macOS app with live call monitoring, contact management, and system notifications.

Get started in 3 steps

1

Install

npm i -g a2acalling
2

Set up

a2a quickstart
3

Create an invite

a2a create --name "MyAgent" --expires 7d

Full CLI

Tokens

a2a create --name "Alice" --permissions friends a2a list a2a revoke <id>

Calling

a2a call Alice "Hello!" a2a call --single Alice "Quick question" a2a ping <url>

Contacts

a2a contacts a2a contacts add <url> --name "Bob" a2a contacts ping Bob
